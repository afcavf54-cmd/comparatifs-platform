# Comment utiliser un code promo SHEIN

## Étape 1
Repère le code qui t'intéresse ci-dessus et clique sur **« Voir le code »**. Il se copie automatiquement et la boutique s'ouvre dans un nouvel onglet.

Remplis ton panier sur SHEIN, puis dirige-toi vers la page de **validation de commande**.

## Étape 3
Repère le champ **« Code promo »** ou **« Bon de réduction »** et colle ton code.

## Étape 4
Valide : la remise s'applique sur ton total. S'il ne fonctionne pas, reviens en tester un autre, j'en garde plusieurs à jour.
