Comment choisir le bon code NAF en restauration ?

Qu'est-ce que le code NAF et pourquoi c'est si important ?

Le code NAF, c'est votre identité administrative. On l'appelle aussi code APE (Activité Principale Exercée). Dans ma boîte, j'ai appris à mes dépens qu'il ne faut pas le choisir au hasard. Ce petit code à 5 caractères détermine votre secteur d'activité, vos obligations, et même vos tarifs d'assurance.

En restauration, le choix est crucial. Mal choisi, vous payez trop cher. Ou pire, vous n'êtes pas couvert par vos assurances en cas de problème. J'ai vu un collègue se retrouver dans cette situation. Pas drôle du tout.

L'INSEE attribue automatiquement ce code quand vous créez votre entreprise. Mais attention : leur attribution n'est pas toujours la bonne. Il faut parfois rectifier.

Les principaux codes NAF en restauration

Voici les codes que vous rencontrerez le plus souvent dans notre secteur :

  • 5610A : Restauration traditionnelle (restaurant classique avec service à table)
  • 5610B : Cafétérias et autres libres-services
  • 5610C : Restauration de type rapide (fast-food, sandwicherie)
  • 5630Z : Débits de boissons (bars, cafés, brasseries)
  • 5621Z : Services des traiteurs
  • 5629A : Restauration collective sous contrat
  • 5629B : Autres services de restauration

La différence entre ces codes ? Tout dépend de votre mode de fonctionnement principal. Si vous servez à table avec des plats préparés sur place, c'est du 5610A. Si c'est du emporter/livrer avec des produits standardisés, plutôt du 5610C.

Quelques exemples concrets

Mon voisin restaurateur a un petit bistrot traditionnel. Menu à 15€, service à table, cuisine maison. Code 5610A parfait pour lui.

Une autre connaissance fait de la restauration rapide : burgers, frites, commande au comptoir. Elle a pris le 5610C. Logique.

Pour les traiteurs, c'est plus simple : le 5621Z correspond exactement à leur activité. Ils préparent pour des événements, livrent, mais ne servent pas sur place.

Comment bien choisir selon votre concept ?

Première question : où vos clients mangent-ils ? Sur place avec service ? À emporter ? Les deux ?

Si c'est principalement sur place avec un vrai service, prenez le 5610A. Même si vous faites un peu de vente à emporter à côté. L'activité principale compte.

Pour la restauration rapide, les critères sont différents. Commande au comptoir, produits standardisés, consommation rapide. Le 5610C s'impose alors naturellement.

Les cafés et bars, c'est le 5630Z. Mais attention : si vous servez aussi des repas complets, ça peut changer. J'ai un ami qui tient un café-restaurant. Son activité principale reste la restauration, donc 5610A.

Les cas particuliers qui posent problème

Food truck : souvent du 5610C, mais ça dépend de ce que vous vendez.

Restaurant avec vente à emporter importante : gardez le 5610A si le service à table reste majoritaire.

Brasserie : si c'est plus restaurant que bar, prenez le 5610A plutôt que le 5630Z.

Traiteur avec coin dégustation : si c'est juste quelques places pour goûter, restez en 5621Z.

Les conséquences financières de votre choix

Votre code NAF influence directement vos coûts. Les assurances professionnelles varient énormément selon le code. Un restaurant traditionnel paie plus cher qu'un simple débit de boissons.

Les cotisations sociales aussi. Certains codes donnent droit à des taux préférentiels ou des exonérations spécifiques.

J'ai calculé pour ma propre entreprise : la différence entre deux codes peut représenter plusieurs centaines d'euros par mois. Sur une année, ça compte.

Autre point important : les aides publiques. Certaines subventions ne concernent que des codes précis. Vérifiez bien avant de faire votre choix définitif.

L'impact sur vos assurances

Les assureurs sont très regardants sur le code NAF. Une restauration traditionnelle n'a pas les mêmes risques qu'un simple café.

Frais de casse, intoxications alimentaires, accidents clients : tout change selon votre code. Un mauvais choix peut vous coûter cher en cas de sinistre.

Comment modifier votre code NAF ?

Vous vous êtes trompé ? Pas de panique. La modification est possible, mais il faut suivre la procédure.

Contactez le Centre de Formalités des Entreprises (CFE) de votre région. Ou directement l'INSEE si vous êtes auto-entrepreneur.

Préparez votre dossier : description précise de votre activité, justificatifs (photos du local, menu, etc.). Plus vous êtes précis, plus c'est rapide.

Délai habituel : 2 à 4 semaines. Parfois plus si votre dossier est incomplet.

Attention : prévenez vos assureurs du changement. Sinon, vous risquez de ne plus être couvert correctement.

Mes conseils pratiques pour éviter les erreurs

Première règle : soyez précis dans votre déclaration d'activité. Plus vous donnez de détails, moins il y a de risque d'erreur de l'INSEE.

Deuxième conseil : vérifiez votre Kbis dès que vous le recevez. Le code NAF y figure. Si c'est faux, rectifiez immédiatement.

Troisième point : demandez conseil à votre expert-comptable. Il connaît les subtilités et peut vous éviter des erreurs coûteuses.

Quatrième astuce : regardez les codes de vos concurrents directs. S'ils ont la même activité que vous, ils ont probablement le bon code.

Enfin, pensez à l'évolution de votre concept. Si vous comptez ajouter de la vente à emporter dans 6 mois, anticipez dès maintenant.

Foire aux questions

Puis-je avoir plusieurs codes NAF ?
Non, vous n'avez qu'un seul code NAF principal. Mais vous pouvez déclarer des activités secondaires.

Mon code influence-t-il mes obligations comptables ?
Indirectement oui. Certains codes ont des obligations spécifiques (notamment en restauration collective).

Dois-je changer de code si j'ajoute la livraison ?
Pas forcément. Si la restauration sur place reste votre activité principale, gardez votre code actuel.

Le code NAF apparaît-il sur mes factures ?
Non, ce n'est pas obligatoire. Mais il figure sur tous vos documents officiels (Kbis, etc.).
